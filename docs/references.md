# 理論依據與參考文獻

## 三個主張，三條理論

| 本 repo 的主張 | 學術名稱 | 一句話 |
|----------------|----------|--------|
| 「拿掉數學還玩得下去嗎？」 | **Intrinsic integration**（內在整合） | 學習內容要嵌在核心遊戲機制裡，而不是插在關卡之間。Habgood & Ainsworth 的對照實驗中，整合版的學習成效與自由選擇遊玩時間都較高。 |
| 「巧克力裹花椰菜」 | Bruckman（1999） | 把樂趣當成糖衣塗在教育內容外面，就像沾巧克力的花椰菜。 |
| 「主題與機制內生連結」 | **Endogenous fantasy**（內在幻想，Malone） | 主題與要學的技能綁在一起（海戰 ↔ 座標攻擊），而非外加包裝（答題換金幣）。 |
| 「機制即評量」「留痕在第 2 步就設計」 | **Stealth assessment**／Evidence-Centered Design（Shute；Mislevy） | 每個遊戲行為都是能力證據，評量嵌在遊戲中、不打斷學習。 |
| 「做的是遊戲式學習，不是遊戲化」 | Game-based learning vs **Gamification**（Deterding） | 遊戲化 = 在非遊戲情境加點數、徽章、排行榜；本 repo 要的是數學在機制核心。 |
| 「設計品質決定成效」 | Clark et al.（2016）統合分析 | 「是不是遊戲」不如「遊戲怎麼設計」重要。 |
| 「有效但不是魔法」 | Byun & Joung（2018） | 數學科 K-12 數位遊戲式學習的整體效果量約 d = 0.37（小至中度）。 |

**誠實定位**：遊戲作為發展活動與形成性評量、配合教學而非取代教學，是較能發揮效果的用法；先校準期待，老師才不會失望。
