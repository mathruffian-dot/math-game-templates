# T7 盤面連線消除（chain-match）— 設計文件

> 模板代號：**T7**｜game id：`chain-match`｜定位：**發展活動**（引擎型機制，可兼作形成性評量）
> 原型：比例消除（Ratio Chain，`games/ratio-tetris/`，v1 俄羅斯方塊 → v2 連連看 → v3 自己串出比例式）。
> 本模板把比例消除的盤面、相鄰連線、消除、掉落補位、無解洗牌抽成**共用引擎**，每個科目只提供「方塊內容＋關係判斷規則」（內容包）。

---

## 0. 為什麼可以跨科

比例消除成功的關鍵不是「數字」，而是：**消除規則本身就是學科關係**。只要一個學科有「把幾個小單位依序串起來，可以判斷成立／不成立，而且不成立的原因有典型誤解」的關係，就能用同一個引擎：

| 科目 | 小單位（方塊） | 串起來的關係 | 典型誤解（kind） |
|------|----------------|--------------|------------------|
| 數學 | 數字 | 兩兩成比，所有比的最簡比相等 | `reversed` 順序顛倒、`mismatch`、`one_to_one`、`odd` |
| 國文 | 單字 | 四字依序組成正確成語 | `typo` 錯別字、`order` 字序錯 |
| 英文 | 詞素（字首／字根／字尾） | 依序組成合法單字 | `wrong_prefix` 否定字首用錯、`order` 字首字尾位置錯 |

不適合的情況：關係只能「辨認」不能「串出來」（例如是非題）、或一條鏈太長（超過 8 格學生無法在盤面上找）。

## 1. 教學目標（每個內容包各自填）

| 內容包 | 學習表現 | 學生將能… |
|--------|----------|-----------|
| `math/ratio` 比例式 | n-IV-6（比、比例式） | 從一群數字中**自己串出**相等的比所組成的比例式，並能說明「比有順序」「1:1 不能當項」 |
| `chinese/idiom` 成語 | 待查（國中國文：字詞／成語運用） | 在相似字干擾下，依正確字序拼出常用成語，並分辨同音或形近的錯別字 |
| `english/affix` 構詞 | 待查（國中英文：構詞） | 用字首、字根、字尾組出合法單字，知道否定字首 un-／im-／in-／dis- 各接哪些字、字首在前字尾在後 |

## 2. 評量證據＋記錄欄位（留痕在這一步就定好）

達標證據＝「在盤面上找出並串成一組成立的關係」的次數與品質，以及失敗時的誤解類型。

| 行為 | 事件 `kind` | `payload` |
|------|-------------|-----------|
| 串出成立的關係 | `chain_ok` | `{v:1, content, tiles:[文字…], len, gain, points, combo, summary, ms}` |
| 串出不成立的關係（有診斷） | `chain_fail` | `{v:1, content, tiles, len, kind, counted, ms}` |
| 盤面無解自動洗牌 | `shuffle` | `{v:1, content, reason:'no_move'|'manual', replanted}` |
| 一局結束 | `game_end` | `{v:1, content, score, matches, tries, fails, maxCombo, durationSec, mode}` |
| 加入／開始 | `join` | `{v:1, content, ns, mode}` |

- `tries`＝計入的嘗試（成功＋`counted:true` 的失敗）；`short`（太短，可能手滑）不計入。
- 分群一律用 `kind`，**不用帶數字或文字的 reason**（reason 只給學生看）。
- `ms`＝從上次消除（或開始）到這次送出的時間，用來看「找關係」花多久。

## 3. 核心機制

- **盤面**：預設 8 欄 × 6 列，每格一個方塊；8 方向相鄰。
- **遊戲動詞**：**在盤面上找出並串成一組成立的關係**（建構）。依序經過的相鄰格就是一條鏈，順序有意義（比的前後項、成語的字序、字首在前字尾在後）。
- **消除**：送出的鏈經內容包 `check()` 判定成立 → 消除、上方掉落、上方補新方塊。
- **不自動連鎖**：補位後就算剛好形成成立的關係，也不會自己消；每次消除都必須是學生自己的判斷（沿用比例消除）。
- **保證有路**：生成時先種入 2～3 條 `plant()` 鏈；之後以有界 DFS（`hasMove`）檢查，無解就洗牌，洗牌多次仍無解就種入新鏈。
- **誘答鏈**：內容包可提供 `plantTrap()`，在盤面種入一條「看起來很像但不成立」的鏈（例如錯別字成語、un-possible），讓學生在辨別中建構。

### 主題與機制內生連結
沒有額外的故事包裝：**方塊就是學科的小單位，消除就是關係成立**。分數只來自成立的關係（長鏈、連續成立），沒有金幣、抽獎。

### 兩問檢驗

**共通（引擎）**
- ① 拿掉學科關係還玩得下去嗎？**不行。**消除規則就是 `check()`；拿掉判斷就沒有任何規則可以決定哪些方塊要消失。這是引擎型機制，不是「答對才能消」的包裝。
- ② 遊戲動詞＝達標證據嗎？**是。**學生不是從選項挑答案，而是在 48 格裡自己決定「從哪一格開始、接哪一格、到哪裡停」，等於自己組出關係（建構）。

**各內容包誠實評估**
| 內容包 | ① | ② 層次說明 |
|--------|---|-----------|
| 數學比例式 | 不行 | 建構：自己選數字、決定順序、組出 a:b = c:d，並一次驗多組比（長鏈）。與原型相同，通過。 |
| 國文成語 | 不行 | **偏記憶提取＋辨別錯別字**：學生要從記憶中提取成語、在盤面找字並排出正確字序，同時避開形近／同音字誘答。屬「建構拼寫」，但認知層次**低於數學包**（不涉及推理，只有提取與辨別）。適合字詞複習與錯別字診斷，不宜宣稱培養理解或運用。 |
| 英文構詞 | 不行 | 建構：用詞素組出合法單字，要判斷字首／字尾的位置與搭配（例如 possible 的否定是 im- 不是 un-）。層次為「規則應用」，高於單純背單字，但仍以辨別為主。 |

## 4. 誤解 → 規則／誘答 → 回饋

### 數學 `math/ratio`（完整移植比例消除 `diagnoseNums`）
| kind | 觸發 | 回饋範例 | 計入 |
|------|------|----------|------|
| `short` | 不足 4 格 | 只選了 3 格，至少要 4 格（兩組比） | 否 |
| `odd` | 奇數格 | 選了 5 格是奇數——比例式要兩兩成對 | 是 |
| `one_to_one` | 某組 a = b | 3:3 化簡後是 1:1，不能當比例式的一項 | 是 |
| `reversed` | 某組是前面那組的顛倒 | 9:6（化簡是 3:2）順序反了——前面是 2:3 | 是 |
| `mismatch` | 化簡後不相等 | 4:5 和前面的 2:3 不相等 | 是 |

`reversed` 與 `mismatch` 必須分開：前者是「不知道比有順序」，後者是「不會化簡或判斷相等」。

### 國文 `chinese/idiom`
| kind | 觸發 | 回饋範例 | 計入 |
|------|------|----------|------|
| `short` | 不足 4 字 | 成語是 4 個字，你選了 3 個 | 否 |
| `typo` | 與某成語只差一字，且該字是登記的常見錯別字 | 「再接再勵」的「勵」應為「厲」：厲，同「礪」，磨刀石，比喻再磨利一次 | 是 |
| `order` | 字對但順序錯 | 這四個字可以組成「按部就班」，順序不對 | 是 |
| `not_idiom` | 其他 | 「一鼓氣作」不是本遊戲的成語（差一個字或順序都不對） | 是 |

誘答：盤面會以較低機率出現登記的錯別字方塊，並種入 1 條錯別字誘答鏈（`plantTrap`）。

### 英文 `english/affix`
| kind | 觸發 | 回饋範例 | 計入 |
|------|------|----------|------|
| `short` | 只選 1 個 | 單字至少要 2 塊（字首＋字根、或字根＋字尾） | 否 |
| `wrong_prefix` | 否定字首換成另一個否定字首就是合法字 | un-possible 不對：possible 的否定用 im-（impossible）。im- 常接 p、m、b 開頭的字 | 是 |
| `order` | 字首不在最前或字尾不在最後 | 字首 un- 要放在字根前面：un + happy = unhappy | 是 |
| `not_a_word` | 其他 | unteach 不是本遊戲收錄的單字 | 是 |

只收國中常見、**拼字不需變形**的組合（例如 happy → happiness 要把 y 改 i，不收，避免混淆）。

## 5. 回饋與計分
- 成功：內容包給 `gain`（預設 鏈長 − 2；數學 4 格 +2、6 格 +4；國文 +3；英文 2 塊 +2、3 塊 +4），乘連擊倍率 `×(1 + combo × 0.5)`，至少 1 分。
- 失敗（`counted:true`）：−1 分（不低於 0），連擊歸零。`counted:false`（太短）不扣分、不斷連擊、不計 tries，只提示。
- 分數付給高層次行為：**長鏈＝一次驗多組關係**、**連續成立＝穩定理解**，不付給手速。
- 回饋：成功→閃光、消除、浮出加分；失敗→該鏈標紅並顯示 reason，停留到下一次操作。

## 6. 鷹架與分層
- 表徵：頂部固定顯示內容包的一句規則（`instructions`），方塊上的字首／字尾以「un-」「-ful」標出位置。
- 即時鏈預覽：串的過程中，頂部顯示目前串成的式子（數學 `2:3 = 4:6`、國文「按部就」、英文 un + happy → unhappy）。
- 提示（三層，每局可用，使用次數留痕）：①策略：重述規則；②指出一條可行鏈的起點；③示範整條可行鏈（閃爍）。用第 3 層後下一次成功不加連擊倍率。
- 難度：先用數學／國文預設盤面；老師可在 README 依範本調整 `board`、`minLen`、`maxLen`。

## 7. 課堂運作（45 分鐘）
- 自主練習：3 分鐘拚分（`?content=…`）。
- 課堂模式：老師 `teacher.html` 選內容包、開房（房號＋QR）、設定時間（預設 5 分鐘），學生 `?room=CODE` 加入後等待；老師按「開始」寫入 `endsAt`；**任一端**偵測時間到都用 `transact` 把 `status` 改 `ended`；老師可提前結束。
- 時間軸建議：建房加入 5 分 → 規則示範 3 分 → 第一輪 5 分 → 看板討論誤解 7 分 → 第二輪 5 分 → 收尾。
- iPad：iOS／iPadOS 預設「點選模式」（依序點格子、點最後一格取消、按「判定」），桌機／Android 拖曳；兩種可切換。觸控目標 ≥ 48px。

## 8. 資料留痕 → 下一節課
- 老師看板（每 5 秒 `listEvents`）：每位學生分數、成功／失敗數、全班誤解 `kind` 長條、最常失敗的組合（tiles 串起來的文字）。
- CSV：逐人摘要、逐筆事件。
- 下一節課：`reversed` 多 → 補「比的順序」；`typo` 集中在某幾字 → 字義對照；`wrong_prefix` 多 → 整理 im-／in-／un-／dis- 的搭配。
- 自願重玩：同一學生在同房的 `game_end` 次數。

## 技術等級
Level 1 單人（自主練習）＋ Level 3 房間（老師控制時間）；學生作答只寫 `mg_events`，房間 state 只放 `{content, status, endsAt, ns, durationSec}`。
