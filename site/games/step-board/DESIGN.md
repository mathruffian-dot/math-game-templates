# T3 拖拉解題板（step-board）設計文件

> 模板：**T3 拖拉建構解題板**｜定位：**發展活動**（例題教學後，學生第一次獨立做同類題）
> 內建三份內容：七上解一元一次方程式、七上比例式求未知數、八上多項式除法（直式）。
> 複製成新遊戲時，請把本檔複製到 repo 根目錄 `games/<slug>/DESIGN.md` 改寫（那裡不會被部署）。

```
遊戲：拖拉解題板（slug：step-board）  模板：T3
單元：七上 一元一次方程式／比與比例式；八上 多項式的除法   學習表現：待查（依教師手冊填入）
定位：發展活動（例題後的第一次獨立練習），兼形成性評量
```

## 1 教學目標（學生將能…）
- 解 ax + b = cx + d：正確**移項變號**、**合併同類項**、**係數化為 1** 並把結果寫成最簡分數。
- 解比例式 a : b = x : c：用**外項積＝內項積**建立等式，代入計算，求出 x。
- 用直式做一次式除二次式：缺項**補 0**，每一輪**決定商項 → 乘回 → 相減**，判斷何時停止並寫出商式與餘式。

## 2 評量證據＋記錄欄位
| 可觀察的數學行為 | 記錄（`mg_events`） |
|---|---|
| 把每一個量放到算式中正確的位置（建立關係） | `card_move`：`{problemId, stepIndex, slot, card, action:'in'/'out', from?, replaced?}` |
| 送出一個完整的數學關係，並在錯誤後修正 | `step_check`：`{content, problemId, problemNo, params, stepIndex, stepKey, stepCount, placement, ok, kind, wrongSlots, hintLevel, errorsBefore, ms, stepScore?}` |
| 需要多少支持才完成 | `hint`：`{content, problemId, stepIndex, stepKey, level}` |
| 獨立完成整題過程 | `problem_done`：`{content, problemId, problemNo, params, steps, errors, hints, ms, score, bonus}` |
| 出席與身分 | `join`：`{content, ns, mode:'class'/'practice'}` |

- `kind` 是穩定的誤解代碼（見第 4 節），老師端只用它分群，不用帶數字的回饋句。
- `problemId = 內容id:種子`，用種子可以重現學生當時的那一題。
- 「首次正確」＝這一步第一次按「檢查」（不含空格未填）就成立；系統代填的鷹架不算學生證據。

## 3 核心機制
- **遊戲動詞**：把卡片（數、項、式）拖進一行算式的空格，**組出這一步的數學關係**，按「檢查這一步」。成立才出現下一步；完成的算式行留在畫面上，下一步引用它。
- 每步 1～3 個空格，只留關鍵操作；已知數字、題目原式、上一行結果都是顯示鷹架。
- 卡片包含正解卡與**誤解卡**（由誤解規則產生，不是隨機 ±1），卡片只能用一次，放錯可以拖回或點掉。
- 接受等價寫法（例：`6x = −12` 與 `−12 = 6x`；外項積兩數交換）。
- 主題就是「把解題過程一行一行搭起來」：板子上留下的就是學生自己的完整算式，與機制一體。

### 兩問檢驗
1. **拿掉數學，還玩得下去嗎？** 不行。沒有「哪一項要變號、哪兩項相乘、商的次數是多少」的判斷，就沒有任何可以做的操作；卡片外觀不透露正解（id 為中性 c1、c2…，誤解卡與正解卡同樣式）。
2. **遊戲動詞＝達標證據的行為嗎？** 是。達標證據是「建立移項後的等式／外項積＝內項積／乘回與相減的結果」，遊戲動詞正是把量放進這些關係的位置；不是從選項挑最後答案（最後答案只是最後一步的其中一格，而且要與左邊自己組的分數一致）。

## 4 誤解 → 規則／誘答 → 回饋（節錄，完整見各 content 檔的 `kinds`）
| 內容 | 誤解（代碼） | 誘答／規則 | 診斷回饋（範例） |
|---|---|---|---|
| 一元一次 | 移項沒變號 `sign_not_flipped` | 同號的項卡 | 右邊的 4x 移到左邊要變號，變成 −4x |
| 一元一次 | x 項與常數放錯邊 `unlike_terms` | 把常數卡放進 x 項格 | 左邊這格要放含 x 的項 |
| 一元一次 | 合併時正負號算錯 `combine_error` | a＋c 的係數卡、d＋b 的常數卡 | 10x − 4x 要連同正負號一起算 |
| 一元一次 | 分數上下顛倒 `frac_inverted` | 分子分母對調、倒數結果卡 | x＝常數 ÷ 係數 |
| 一元一次 | 除以原係數 `divide_wrong_object` | 原係數 a 卡 | 要除以合併後的係數 |
| 比例式 | 同一個比的兩項相乘 `same_ratio_product` | x 配同一個比的另一項 | x 是外項，要配另一個外項 |
| 比例式 | 外內項配錯 `outer_inner_mixed` | x 配到另一個比的錯誤項 | 和 x 相乘的是另一個外項 |
| 比例式 | 相加代替相乘 `add_not_multiply` | m＋n 卡 | 外項積是相乘不是相加 |
| 多項式除法 | 缺項沒補 0 `missing_term_alignment`／當成 1 `missing_term_as_one` | 常數往前擠、+x 卡 | 缺 x 項要寫 +0x |
| 多項式除法 | 商次數錯 `quotient_degree` | x² 次的商項卡 | x² ÷ x = x |
| 多項式除法 | 相減沒變號 `subtract_sign` | 上下相加的結果卡 | 減負數要變加 |
| 多項式除法 | 餘式次數未小於除式就停 `remainder_degree` | 第一輪餘式卡 | 餘式次數要小於除式 |

## 5 回饋與計分
- 即時回饋：錯的空格標紅，顯示「誤解名稱＋一句診斷」；空格沒填只提醒、不扣分。
- **完成一步才得分**：每步 10 分；錯一次 −1（每步最多 −3）；提示第 1／2／3 層累計 −2／−4／−6；每步最低 3 分（不歸零，永遠有退路）。
- 整題零錯誤、零提示 +5（付給獨立完成的高層次行為）。不能跳過過程直接交答案。
- 狀態列「連續一次成立」＝連續幾步沒有錯誤也沒用提示。

## 6 鷹架與分層
- 表徵：題目原式 → 已完成的算式行（綠底）→ 目前算式行（藍框）；直式用表格讓同次項對齊。
- 三層提示：①方向（策略）②關鍵關係（指出要算什麼）③幾乎給出一個槽（並閃爍標出該空格與卡片）。
- 難度：參數隨機但保證整數或簡單分數；多項式除法約一半題目有缺項、約三成首項係數為 2。

## 7 課堂運作（45 分鐘）
- 0–5 分：老師在 `teacher.html` 選內容與時間、開課堂，投影 QR；學生輸入班級-座號加入（等待畫面）。
- 5–25 分：老師按「開始」，學生各自解題；老師看即時看板，閒置超過 90 秒的學生標橘色，走過去協助。
- 時間到（或老師按「提前結束」）學生畫面停止；任一端看到 `endsAt` 已過都會把房間推進到 `ended`，不綁老師分頁。
- 25–45 分：依「全班最常見的誤解」與「卡最久的步驟」做全班講解；搭配紙筆出口題確認獨立表現。
- iPad 假設：觸控目標 ≥ 48px；拖拉與「點卡片再點空格」兩種操作都可。

## 8 資料留痕與報告
- 老師端每 5 秒讀 `listEvents` 整理：每位學生目前第幾題第幾步、完成步數、首次正確率、提示、最常見誤解；全班誤解長條圖；各步驟平均完成秒數（卡最久的步驟）。
- 匯出 CSV：逐人摘要、逐筆事件（每次檢查的放法、誤解代碼、錯的槽、提示層級、秒數）。
- 自願重玩指標：課堂結束後學生點「自主練習」的事件（`room = null`，`mode:'practice'`）。
- 下節課用法：挑誤解次數最多的 1～2 個代碼做全班討論；首次正確率低的步驟重做例題。

技術等級：3 多人即時（課堂房間＋事件留痕）；無房號時為 1 單人練習。
